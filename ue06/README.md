# Übung 6 — Modellieren von Hand und mit dem Agenten

In dieser Übung zeichnen Sie ein Use-Case-, ein Aktivitäts-, ein Klassen-
und ein Zustandsdiagramm des Terminplaners, jedes zuerst mit Bleistift auf
Papier und danach mit einem Agenten in PlantUML bzw. Mermaid. Die Aufgaben
stehen im
[Übungsblatt](https://carstenlucke.github.io/thm_wk-1208_softwaretechnik/ue06-modellierung/),
die Beschreibungen, nach denen Sie modellieren, in [`fall.md`](fall.md).

## Was Sie einreichen

Einzureichen ist ein Verzeichnis `ue06/<benutzername>/`, und zwar als Pull
Request vom Branch `ue06-<benutzername>`. Gemeint ist Ihr GitHub-Benutzername
in Kleinbuchstaben.

| Datei | Aufgabe | Woher |
|---|---|---|
| `hand-usecase.jpg`, `usecase.puml` | 1 — Use-Case-Diagramm | Foto Ihrer Zeichnung, PlantUML vom Agenten |
| `hand-aktivitaet.jpg`, `aktivitaet.puml` | 2 — Aktivitätsdiagramm | Foto Ihrer Zeichnung, PlantUML vom Agenten |
| `hand-klassen.jpg`, `klassen.md`, `klassen-regeln.md` | 3 — Klassendiagramm | Foto Ihrer Zeichnung, Mermaid vom Agenten |
| `hand-zustand.jpg`, `zustand.md` | 4 — Zustandsdiagramm | Foto Ihrer Zeichnung, Mermaid von Ihnen |
| `vergleich.md` | 1 bis 4 und „Vor der nächsten Vorlesung“ | aus `_vorlage/` |

Statt `.jpg` geht ebenso `.png`.

1. Kopieren Sie das Verzeichnis `_vorlage` nach `<benutzername>`. Die Vorlage
   selbst bleibt unverändert.
2. Legen Sie die übrigen Dateien im Lauf der Übung hinzu.

Alle Aufgaben bearbeiten Sie allein. `fall.md` lesen Sie nur; ändern Sie
dort nichts.

> [!IMPORTANT]
> Für diese Übung gibt es 1 Bonuspunkt. Diesen erhält nur, wer bis zur
> Frist im Moodle-Kurs selbst einen Pull Request mit Inhalten gestellt hat.
